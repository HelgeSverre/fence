Fence modifications: converted sRGB colors to oklch; mapped editor and panel
backgrounds to Fence panes, Markdown tokens to source highlighting, and syntax
colors to Fence’s grouped preview code tokens. Link colors supply the accent
for readable links and controls; other interaction states use Fence’s derived
accent colors. Zed-only UI and semantic token styles are omitted.
