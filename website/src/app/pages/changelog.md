# Changelog

## 0.1.1

- Expanded HTML tag support in the Markdown renderer.
- Added missing preview styles.
- GitHub Actions bumped to v5 to fix Node.js 20 deprecation warnings.
- Auto-publish GitHub releases after all builds complete.

## 0.1.0

- First public release.
- Split-view editor with file tree, editor, and live preview.
- Multiple themes using oklch colors.
- YAML frontmatter parsing and rendering.
- Resizable panes with persisted layout state.
- Recent-workspaces tracking.
- File watching with chokidar — files reload automatically when changed
  outside the app.
